# 订阅协议 v1

实现日期：2026-11-24。服务端以 `internal/domain/config.go`、`internal/httpapi/server.go` 为准；Android 对应 ManagedConfiguration、SubscriptionClient、SubscriptionController。结构见 [JSON Schema](subscription-v1.schema.json)，示例见 [配置样例](subscription-v1.example.json)。样例均为虚构数据。

## 链接和身份

`https://hub.example.com/api/v1/subscriptions/{id}/config#{token}`。可在 `/api` 前增加部署路径前缀。

id 是 32 位小写十六进制随机标识；token 为 32 随机字节的无填充 Base64URL 编码（43 字符）。每人一个订阅，可供其多台设备使用。token 只在创建/轮换时展示，服务器保存 SHA-256 摘要。链接本身是访问凭据，不得记录、截图或分享给其他人。

客户端剥离 fragment，将 token 放入 `Authorization: Bearer ...`。不接受 URL 用户信息、query、非 HTTPS 地址或跨站重定向；不跳过系统证书校验。订阅使用独立直连网络客户端，不依赖或附带下发的 HTTP 代理/Jellyfin 凭据。端点不支持在浏览器地址栏直接获取配置，因为 fragment 不会作为 HTTP 请求发送。

## 获取完整快照

`GET /api/v1/subscriptions/{id}/config`

必需请求头：Authorization、`X-Client-Version-Code`（正整数，Android 首版为 56）。已有成功快照时附带 `If-None-Match`。响应体上限 64 KiB。

| 状态 | 行为 |
| --- | --- |
| 200 | JSON 完整配置及 ETag；客户端严格校验后构造候选 |
| 304 | 版本未变；仅更新检查时间，不重新登录或重建播放器 |
| 401/403 | 链接不可用；当前正在使用的订阅标为失效，阻止新播放 |
| 410 | 订阅已停用；与上述失效处理一致 |
| 409 | 尚未发布；保留已有可用配置，提示稍后重试 |
| 426 | App 版本不满足 minClientVersionCode；保留旧配置并提示升级 |
| 429/5xx/超时 | 保留最后成功配置，退避重试 |

服务端在比较 ETag 前检查令牌、启用状态和客户端版本，不能使用 304 绕过停用。响应 `Cache-Control: private, no-cache`，`Vary: Authorization, X-Client-Version-Code`。代理不得共享缓存配置响应。错误体为 `{ "code": "脱敏类别", "message": "固定提示" }`，不包含地址、密码或令牌。

核心字段：schemaVersion 固定 1；subscriptionId 与链接一致；revision 从 1 递增；minClientVersionCode 为最低兼容版本；refreshIntervalSeconds 为 300～86400，默认 900。connection 包含 HTTP 代理和 Jellyfin 授权；playback 为分辨率及音视频合计码率上限（bps）。0 码率表示自动，auto/screen 分辨率语义沿用客户端现有策略。枚举见 Schema。

不下发字幕或音轨偏好。首选语言继续由 App 读写 Jellyfin 账号设置；播放时选轨、关闭字幕继续由播放会话处理。

## 应用与恢复

首次导入、代理或授权改变时，先通过候选代理调用 Jellyfin 登录；成功后才覆盖原配置。解析、连接或鉴权失败不得清空最后成功配置。缓存使用 Android Keystore 独立密钥加密；不保留旧手动配置入口，也不读取旧配置自动登录。未配置订阅或缓存损坏时展示导入入口。

播放期间不替换连接；已验证候选保留至退出播放，随后应用。后续暂时刷新失败不丢弃这个候选。画质更新不重建当前流，在下一次取流或切集时采用；同一影片切音轨/字幕仍保留本次播放的策略。显式停用不强行中断当前流，但禁止新取流/切集。

新版本必须单调增加；相同版本内容不得改变。回滚发布一个更高版本的旧内容。令牌轮换独立于配置版本，旧链接立即失效。客户端启动先用成功缓存，再在前台异步检查；默认约 15 分钟刷新，带抖动和退避，不要求后台常驻。Hub 短暂不可用时仍可使用缓存，但媒体代理与 Jellyfin 自身必须可用。已下发的凭据不能远程抹除，停用需客户端下次成功联机获知，不能保证离线即时撤权。

## 状态反馈

`POST /api/v1/subscriptions/{id}/feedback`，同一 Bearer 身份，JSON 字段：deviceId（16～128 字符设备标识）、platform（android/ios）、versionCode、revision、status、errorCode。status 为 synced/applied/pending/error；errorCode 为 NETWORK/PROXY_AUTH/JELLYFIN_AUTH/UNSUPPORTED_CONFIG/REVOKED 或空字符串。不得上传原始异常、URL、认证信息。

服务端按订阅散列设备标识，每个订阅仅保存最近 50 条反馈。第一版 Android 主动上报 applied/pending；后台展示最近反馈，不代表设备当前在线。管理 API 与订阅身份隔离：登录 Cookie 为 HttpOnly/Secure/SameSite=Strict，写操作要求同源 Origin 与 X-CSRF-Token；草稿保存、预览、发布、回滚、启停和轮换各有独立操作。

## 加密边界

HTTPS 提供传输加密，JSON 响应内字段不再做自定义端到端加密，因此 TLS 终止入口能看到明文配置；生产不支持 HTTP 订阅。服务器数据库实体和发布快照使用 AES-256-GCM，随机 nonce、带记录上下文 AAD，主密钥单独只读文件挂载。管理员密码 Argon2id 哈希；订阅 token 仅保存摘要。Android 成功快照与链接使用独立 Keystore AES-GCM 加密保存。

数据库与主密钥分别备份，错误密钥拒绝打开已有数据；丢失主密钥不能恢复凭据。不能将数据库静态加密理解为允许明文 HTTP 下发。
