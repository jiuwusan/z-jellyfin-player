本目录为大字版设计参考。Android 从 0.6.22 起按本方案替换默认界面，不提供两套 UI 切换；iOS 尚未同步实现。代理、授权和播放策略沿用现有设置，服务器配置不变。图像沿用已有设计素材，所有账号和服务器均为虚构样例，不连接真实 Jellyfin。

保留原有的手机比例预览和桌面评审侧栏，不将手机界面横向拉伸。页面背景覆盖完整浏览器可视区，不使用固定桌面仿真视口，以免产生右侧或底部的白色留白。窄屏直接显示手机页面，横屏播放器沿用原有预览方式；三页总览仅用于并排比较。

横向卡片栏支持桌面鼠标拖动，松手吸附最近卡片；移动达到 8 px 才识别为拖动，并拦截随后产生的点击，防止误播放。小幅移动和普通点击仍然有效，手机触摸滑动保持浏览器原生行为。与原版共用 `../rail-drag.js`。

## 设计方向

目标是在手机上更容易看清文字、区分操作、准确点击。保留熟悉的 Jellyfin 深色和蓝色体系，采用独立的大字排版，而非整体等比放大。

- 正文约 20，卡片标题 22–24，区块标题 26，详情片名 30；关键辅助信息不小于 16，常用信息采用 17–18。原型单位为 CSS px，未来原生实现需区分 sp 与 dp，并适配系统字体设置。
- 主文字白色，辅助文字采用浅灰 `#d2d2d2`，主操作使用亮蓝 `#70d5f5`。遮罩保证封面上的时长容易辨认，不将文字颜色作为唯一选中提示。
- 主要按钮至少 56 高。顶栏图标附带「返回」「搜索」「设置」文字，底部导航保留图标及 20 号文字。选中标签同时使用字重和下划线。
- 保留已确定的小圆角体系，减少细小装饰，主要靠字号、间距和明暗组织层级。

## 页面变化

| 页面 | 大字版方案 |
| --- | --- |
| 首页 | 首页只显示一个区块：有未看完记录时为继续观看，没有时改为最近添加；最近添加沿用继续观看的横版大卡片，隐藏观看时间和进度。移除接下来模块。首页卡片占满内容区宽度，单列纵向排列，整页上下滚动；时长用更大白字及深色遮罩。最近添加一屏约两张卡片。点击策略保持原样。 |
| 媒体库 | 两列海报，标题最多两行，类型和年份以 17 号浅灰显示。标签 20 号、至少 58 高。默认添加时间倒序，沿用服务端聚合及现有分页、刷新和返回逻辑。示例稿为静态样例，不模拟真实网络分页。 |
| 详情 | 保留背景渐变和竖版海报。片名和年份位于海报右侧，播放操作在其下独占一行，避免大字挤在右侧。主播放蓝字，次操作灰白色。季标签、集列表和简介整体增大。 |
| 播放器 | 保持横屏全屏，顶部按钮和轨道菜单放大；进度、时间与播放操作分为两行，字幕字号增大。保留原有 5 秒自动隐藏和播放交互，弹出菜单或暂停时不隐藏。 |
| 设置 | 大标题和下横线输入，字段、输入值、错误提示均放大；画质选项上下排布，避免两列长标签拥挤。点击保存后仍弹窗输入确认密码。 |

## 评审重点与待验证项

- 先确认大字密度、两列海报、带文字图标，以及详情独立播放操作行是否合适。
- 首页「继续观看」的集号位于封面左下角、时长上方，与时长左对齐。采用紧凑的「第1集」写法，第2季起显示「第2季 第1集」；集号采用 20 号中等字重白字和阴影，依靠封面渐变保证可读性。电影／剧集类型放到封面右上角，年份以括号接在标题之后，单集采用所属剧集的年份。下方不再单列类型和年份，标题区统一单行高度，标题及括号年份超出时以省略号收尾，不再预留第二行，以保持电影和剧集卡片等高。仅调整继续观看，其他卡片保持原样。「接下来」模块已移除。
- 大字会减少首屏内容；保持正常滚动和清晰分组，不缩小辅助文字来强行装下更多内容。
- 320–430 宽度检查长片名、长媒体库名称、按钮换行和设置字段；原生实现前再用目标手机及系统大字体实测，不把网页截图当成真机验收。
- 本轮不引入自动判定视力、强制切换模式或新增业务能力，Android 使用本方案作为唯一默认 UI。

## 首页单区块设计更新（已确认）

Android 0.6.23 已同步本段首页规则。首页有续播记录时只显示「继续观看」；没有时显示「最近添加」，复用相同的横版封面、卡片宽度、类型角标及单行标题／括号年份。无续播卡片不展示已看时间或进度条，单集的集号下移至封面左下角。首页卡片主体均进入详情，单集进入所属剧集详情；仅播放图标播放或续播；无可用媒体时显示空状态。评审侧栏分别提供「首页 · 继续观看」和「首页 · 最近添加」，均有独立 HTML 预览入口和截图；仅用于查看两种示例状态。

首页滚动方式更新：继续观看及无续播时的最近添加均采用单列纵向列表，横版封面不变，每张卡片填满内容区宽度，卡片间距 20 px。由页面统一上下滚动，顶部栏和底部导航保持固定；首页不再使用横向拖动或松手吸附，其他页面交互不变。此项已同步 Android 0.6.23，iOS 尚未实施。

两个首页预览入口复用同一份交互原型与样式，保持手机比例、桌面侧栏及满屏背景；无需修改地址参数。入口只用于设计评审，不是 App 中的 UI 切换功能。

## 首页卡片点击更新（Android 0.6.24）

两张首页设计稿均使用独立详情和播放按钮。点击封面、标题等卡片主体进入详情，单集指向父剧；右下角的播放图标单独播放或续播，剧集图标沿用详情的播放目标。视觉图标 44 px，点击区域 56 px，键盘可以分别聚焦，不嵌套按钮，点击图标不会同时打开详情。媒体库与详情内选集交互维持原规则。
