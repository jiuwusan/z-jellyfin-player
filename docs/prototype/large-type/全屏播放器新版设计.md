# 全屏播放器 · 中央大按钮方案

[交互预览](player-redesign.html?state=paused) · [满屏预览](player-redesign.html?focus=1&state=paused) · [电影合集](player-redesign.html?content=collection&state=paused) · [原版对照](home-resume.html?screen=player)

用户选择中央大按钮布局。Android 0.6.54 已按本稿实施，服务端和连接配置未修改。网页预览仍使用已有虚构媒体素材，不请求真实 Jellyfin，也不保存账号或语言设置；iOS 尚未同步。

## 布局

顶部保留返回、片名、集号或合集名，字幕和音轨位于右侧。使用矢量图标与文字配对，减少按钮边框，用上下渐变保证深浅背景上的对比度。

中央操作按「上一集—后退 5 秒—播放／暂停—前进 15 秒—下一集」排列。主按钮采用浅色圆形底且最大，前进后退图标次之，上下集图标稍小；每项保留文字与独立触控区域。合集两端改为上一部／下一部，普通电影隐藏两端按钮。

底部只保留时间、画质上限与进度条，不再重复上下集／部。播放位置使用白字，总时长与画质使用浅灰；亮蓝只强调已播放进度、选中的轨道与主要操作状态。

| 内容 | 中央两端操作 |
| --- | --- |
| 剧集 | 上一集、当前集序号、下一集 |
| 电影合集 | 上一部、当前部序号、下一部 |
| 普通电影 | 隐藏上下部导航，不出现禁用的剧集按钮 |

大屏预览主按钮约 80–108 CSS px，移动横屏约 80；极矮横屏约 64。标题约 23–34，常用操作约 18–24，字幕约 22–32。原生落地时需按 dp／sp、系统字体与安全区重新验收，不能直接把网页像素等同于真机尺寸。

## 交互

- 正常播放 5 秒无操作后，顶部、中央和底部控制区一起隐藏。点击画面可显示或隐藏；暂停、缓冲、拖动进度或打开菜单时保持显示，操作结束重新计时。
- 缓冲状态在底部时间和画质之间显示小转圈和提示，保留中央暂停和进度操作，不用加载提示替换整个控制区。
- 字幕与音轨沿用无标题、无关闭按钮的气泡菜单，尖角指向触发按钮。实际列表可滚动，选择项使用蓝色与对勾双重标记，关闭字幕位于最后。
- 点击选项、画面空白或 Escape 收起菜单；关闭字幕后示例文字消失，重新选择后恢复。这里仅演示 UI，不模拟服务器转码或音轨协商。
- 操作区始终水平、垂直居中，刘海安全区仅影响操作宽度，不偏移中心。文字字幕显示为白字加描边／阴影，不加黑色背景块；固定在视频常规底部位置，不为工具栏预留高度，控制区显隐不改变位置或字号，允许进度条临时覆盖。服务端烧录字幕的位置仍随视频本身。
- 保留既有播放规则：普通电影／末集结束返回；合集按队列连播，末部返回。预览仅用少量样例演示切换与状态，不代替真实取流、会话上报或自然结束验收。

桌面保留侧栏与横屏播放器的评审方式，背景填满浏览器。满屏链接隐藏评审侧栏；手机竖屏预览旋转横屏画幅，横屏时铺满视口，不产生白色留边。

## 已检查

浏览器检查了桌面评审布局、640×360 移动横屏和 390×844 竖屏模拟：没有页面横向溢出，轨道气泡保持在视口内。5 秒隐藏、点击唤回、暂停／缓冲／菜单保持显示、字幕关闭与恢复、字号保持、音轨选中、合集上下部文案、普通电影隐藏切换入口均通过交互检查。缓冲时仍可点击中央按钮暂停。

Android 0.6.54 已安装荣耀，并通过中央五按钮、菜单、5秒显隐、加载态、结束返回检查。短时实播验证了硬解与重试续播，详情见[实施与验收记录](../../superpowers/plans/2026-11-25-android-player-redesign.md)。未提交或推送。
