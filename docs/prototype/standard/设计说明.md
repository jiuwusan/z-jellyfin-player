# 标准版 UI · 轻量观影

日期：2026-11-25。独立设计提案，仅修改设计稿，不修改 Android、iOS 或 Hub。

沿用现有大字版已确认的交互，提供更适合日常观影的标准字号和密度。保留 Jellyfin 青蓝品牌色、深色画面和小圆角，以清晰的字重层级、低对比边框和紧凑导航替代整体放大。

| 区域 | 标准版设计 |
| --- | --- |
| 基础字号 | 正文 14–15，辅助信息 12–13，页面标题 22；主要点击区域至少 44 |
| 顶部与导航 | 56 高顶部栏，工具仅显示矢量图标；底部图标配 11 号文字，青蓝标记当前页 |
| 首页 | 只有继续观看，纵向滚动；无续播时单独预览最近添加，同用横版卡片。仅播放图标起播，卡片进入电影/剧集详情 |
| 续播卡片 | 横版背景、右上角类型、左下角季集及已看/总时长、底部细进度；片名与括号年份单行省略 |
| 媒体库 | 顶部为实际媒体库标签，没有全部；标准手机 3 列海报，片名 14、信息 12，电影系列进入成员列表 |
| 详情 | 保留背景渐变和封面叠放；电影、剧集共用封面右侧播放区；选季使用横向标签，单集点按直接播放 |
| 设置 | 订阅/播放两个 Tab，订阅脱敏、复制/同步/更换，服务下发项只读；语言及默认音轨偏好可操作 |
| 播放器 | 横屏、中央大按钮，两侧快退/快进及上下集/部；字幕/音轨无标题气泡，关闭字幕在最后；5 秒隐藏，暂停/拖动/菜单时保持，字幕位置固定 |

两版共用业务与查询语义；字号不通过全局缩放实现，触控区域不随文字一起缩小。海报列数属于本版密度提案，待预览确认。原大字版设计保持原样。

## 预览与边界

入口为 [标准版](index.html)。独立预览：[继续观看](index.html?screen=home)、[无续播](index.html?screen=home&feed=latest)、[媒体库](index.html?screen=library)、[剧集详情](index.html?screen=detail&item=detective)、[电影详情](index.html?screen=detail&item=forest)、[设置](index.html?screen=settings)、[播放器](index.html?screen=player)。背景填满浏览器，桌面保留手机画幅与左侧评审导航，手机直接使用全视口，不留白色边缘。

所有媒体、链接、账户和进度为演示数据，复用现有原型图片；不请求服务器、读取实际凭据或保存 App 配置。复制的是虚构订阅链接。原型中仅演示画面和进度，不进行真实解码、转码或会话上报。功能落地仍需单独确认与真机验收。

## 本轮预览核对

- 1360×1000 桌面、390×844 手机、320×740 小屏及 844×390 横屏检查通过，无页面横向溢出或白色留边。横屏播放器的中央操作区在两个方向居中，轨道气泡未越出视口。
- 首页单集卡片进入剧集详情，播放按钮从示例进度续播；详情返回首页正常。无续播链接独立展示最近添加，不出现虚构进度条或时间。
- 媒体库为三列，没有全部标签；电影系列进入有序成员列表，成员可进电影详情。
- 原型播放器 5 秒隐藏、暂停保持、字幕关闭、音轨切换及固定字幕位置核对通过；不代表实际媒体播放验收。
- 设置两 Tab、语言选择、更换订阅的保存后确认弹窗、错误密码与正确密码流程核对通过。对话框在桌面手机画幅中心显示。
- JavaScript 语法及 CSS 解析通过，浏览器控制台无错误。当前仅新增本目录文件，原版、大字版和 Android 均未修改；未提交或推送。

## Android 实施记录（2026-11-25）

用户确认后已将标准版落实到 Android 0.6.59，并增加本地「长辈模式」开关。原型保留为评审入口，示例数据不与真实服务同步。Android 按用户最新确认默认使用标准模式，保留已保存的选择，荣耀本轮切换为标准版供试用；验收范围与实际结果见 [Android 标准版 UI 验收](../../requirements/Android标准版UI验收.md)。
