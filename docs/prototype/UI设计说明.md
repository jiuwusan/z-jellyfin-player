# Jellyfin 家庭影音 UI 设计

[打开可点击设计稿](index.html) · [首页预览](首页预览.png) · [媒体库功能需求](../requirements/媒体库功能需求.md)

面向手机竖屏。首页优先展示未看完的影片，媒体库从底部导航进入。海报帮助识别内容，文字和主按钮指引操作。桌面评审视图左侧可直接切换页面，手机宽度只显示 App 界面。

## 页面

| 页面 | 布局与操作 |
| --- | --- |
| 首页 | 从上到下显示「继续观看」「接下来」「最近添加」。继续观看用横向封面、进度条及时间，播放标识在封面右下角；接下来横向滑动，显示剧名、季集号和集名；最近添加用竖版海报。点整张卡进入对应详情。 |
| 媒体库与搜索 | 顶部横向标签使用当前账号可访问的 Jellyfin 视频媒体库名称。「全部」默认选中，直接展示电影与剧集；选择具体库时直接展示该库的媒体。结果采用 2:3 海报网格，标题最多两行，点击进入详情。常规手机三列，窄屏两列。搜索复用相同卡片，返回时保留搜索词和浏览位置。 |
| 电影与单集详情 | 封面向页面背景渐变，片名、元数据和简介依次排列。有进度时主按钮为「继续观看」，旁边保留「从头播放」，并展示已看时间；已看完时使用「重播」。 |
| 剧集详情 | 「选集」下横向显示季标签，多季时可滑动，单季直接列出集数。每集显示封面、集号、标题和时长；已看完的单集显示带对勾的「已看完」，续播中的单集显示已看时间。 |
| 连接设置 | 用标题和分隔线组织「家庭 HTTP 代理」「Jellyfin 授权」「播放画质」，输入框使用下横线，密码遮挡。画质沿用原型中的 Jellyfin 档位，默认 1080p／4 Mbps，码率为音视频合计。 |
| 保存确认 | 点击「保存并连接」后弹窗输入确认密码。错误状态显示在输入框下方，留在弹窗重试；取消保留原有保存值和页面草稿。确认成功后在保存按钮下方说明结果。 |

## 视觉与布局

- 背景采用深紫色 `#16121D`，面板 `#241C2E`，主文字 `#FAF3FC`，次要文字 `#D1C2D9`。浅紫 `#E4C5FF` 用于主操作、进度和当前标签；绿色 `#B5E7D7` 用于已看完状态，并辅以文字和图标。
- 页面边距常规 20、窄屏 16；区块标题 20，详情片名 30–36，主要按钮高 48，图标、季标签和设置输入框的触控区域至少 44。以上尺寸在原型中使用 CSS px，原生端按 dp／pt 和系统字体缩放适配。
- 海报采用 2:3，首页续播与接下来封面、剧集单集缩略图采用 16:9；渐变遮罩保证叠在封面上的入口文字和进度清晰。横向卡片栏露出部分下一张封面以提示滑动。
- 底部导航固定显示「首页」「媒体库」「设置」。当前入口通过底色和文字突出，按键焦点有独立描边。

## 数据状态与原生交接

- 首页各区块独立加载。加载中保留区块标题与等比例占位，失败时在区块内提供重试；无续播记录时显示「暂无未看完的影片」，空的「接下来」和「最近添加」可收起。
- 媒体库上滑接近底部时自动追加下一页，加载中在列表末尾显示提示。首屏或分页失败时提供重试，分页失败保留已有内容。海报缺失或失败使用等比例占位，标题和点击入口照常显示。播放详情缺少年份、时长或简介时省略对应字段。
- 确认通过后，原生设置页可显示连接中、成功，或代理、服务器、授权对应的错误；临时失败保留上次成功配置。首次配置和更新已保存配置的确认规则以功能需求为准。
- 可点击稿使用示例数据，支持浏览、搜索、切季、模拟续播和设置确认。加载、缺图、网络故障和分页失败的样式行为在本说明中定义，真机和真实服务交由原生实现验收。
