# z-jellyfin UI 设计

[打开可点击设计稿](index.html) · [剧集详情](index.html?screen=detail) · [电影详情](index.html?screen=detail&item=forest) · [全屏播放器](index.html?screen=player) · [首页预览](首页预览.png) · [开屏预览](开屏预览.png) · [媒体库功能需求](../requirements/媒体库功能需求.md)

浏览页面向手机竖屏，播放器面向横屏。首页优先展示未看完的影片，媒体库从底部导航进入。桌面评审视图左侧可直接切换页面，点击「全屏播放器」可查看宽屏设计。

## 页面

| 页面 | 布局与操作 |
| --- | --- |
| 首页 | 首屏优先展示大幅横向「继续观看」卡片。已看／总时长显示在封面左下角、进度条上方。片名和季集号（电影显示类型和年份）留在封面下方。点整张卡片从保存的位置续播，退出播放回到首页。下面是横向浏览的「接下来」和采用 2:3 海报的「最近添加」。单集直接播放，电影和剧集进入对应详情页。 |
| 媒体库与搜索 | 顶部横向标签使用当前账号可访问的 Jellyfin 视频媒体库名称。「全部」默认选中，直接展示电影与剧集；选择具体库时直接展示该库的媒体。结果采用 2:3 海报网格，标题最多两行。电影和剧集进入详情页，单集直接播放。常规手机三列，窄屏两列。搜索复用相同卡片，返回时保留搜索词和浏览位置。 |
| 电影详情 | 横版背景铺在顶部，底部用深色渐变过渡到信息区，2:3 竖版海报从左侧跨过背景下缘。片名和元数据居中放在深色信息区的右侧，播放操作排在右侧年份下方，简介在信息区之外。有进度时提供「继续观看」和「从头播放」，已看完时使用「重播」。 |
| 剧集详情 | 顶部沿用电影详情的横版背景与竖版海报布局。下方显示简介和选集，播放入口统一放在封面右侧、年份下方，使用蓝色图标和文字的弱描边按钮；有进度时并排提供灰白色「从头播放」，从当前续播目标单集的片头开始。优先续播未看完的一集，否则播放第一集未看内容。多季时可滑动切季。每集显示封面、集号、标题和时长。点某一集直接播放，退出播放器回到选集列表。已看完的单集显示带对勾的「已看完」，续播中的单集显示已看时间。 |
| 全屏播放器 | 播放时画面铺满横屏播放器，并按原始比例适配。左上角是返回和集名，右上角是字幕、音轨；底部显示进度、时间、画质上限和播控。点画面可显示或隐藏控制区。 |
| 连接设置 | 用标题和分隔线组织「家庭 HTTP 代理」「Jellyfin 授权」「播放画质」，输入框使用下横线，密码遮挡。画质沿用原型中的 Jellyfin 档位，默认 1080p／4 Mbps，码率为音视频合计。 |
| 保存确认 | 点击「保存并连接」后弹窗输入确认密码。错误状态显示在输入框下方，留在弹窗重试；取消保留原有保存值和页面草稿。确认成功后在保存按钮下方说明结果。 |

## 视觉与布局

- 配色来自 Jellyfin Web 默认 Dark 的核心色值。页面背景 `#101010`、面板 `#202020`、主文字 `#FFFFFF`、次要文字 `#B8B8B8`。亮蓝 `#00A4DC` 用于主操作和续播进度，配深色前景 `#061820`。媒体库选中项使用蓝色文字和短下划线，季标签、底部导航选中项和「已看完」使用淡蓝底搭配蓝色文字或图标。 [Jellyfin Web 12.4 默认深色主题](https://github.com/jellyfin/jellyfin-web/blob/v12.4/src/themes/_base/theme.ts#L5-L30)
- 页面边距常规 20、窄屏 16；区块标题 20，详情片名 30–36，主要按钮高 48，图标、季标签和设置输入框的触控区域至少 44。以上尺寸在原型中使用 CSS px，原生端按 dp／pt 和系统字体缩放适配。
- 单集缩略图和「已看完」标记使用 4 的圆角，海报、按钮和季标签使用 6，续播卡片、确认弹窗和轨道面板使用 8。播放图标和进度拖点保持圆形。
- 海报采用 2:3，首页续播与接下来封面、剧集单集缩略图采用 16:9；渐变遮罩保证叠在封面上的入口文字和进度清晰。横向卡片栏露出部分下一张封面以提示滑动。
- 详情页参考 Jellyfin Web 移动布局。横版背景随视口高度调整，竖版海报跨在背景与深色信息区之间。右侧文字从信息区内开始，电影和剧集的播放操作均放在右侧年份下方，主按钮使用蓝色图标和文字，「从头播放」使用灰白色。 [Jellyfin Web 移动详情布局](https://github.com/jellyfin/jellyfin-web/blob/v10.11.11/src/styles/librarybrowser.scss)
- 「继续观看」在封面右下角用直径 34 的半透明深色圆底、白色矢量三角和淡白描边提示整张卡片可续播。「接下来」卡片只显示封面、剧名和季集号。
- 首页「继续观看」「接下来」和「最近添加」的单集卡片在剧名下显示季集号。第 1 季只显示集号，如「第 3 集」。第 2 季起显示季数和集号，如「第 2 季 · 第 1 集」。集名在播放器顶部和剧集选集列表显示。
- 单集直接打开播放器。有未看完的进度就续播，首次观看或已看完则从片头开始。退出后回到播放前的页面。
- 底部导航固定显示「首页」「媒体库」「设置」。当前入口通过底色和文字突出，按键焦点有独立描边。

## 全屏播放

- 用上下渐变保证控制区对比度。底部进度条沿用亮蓝色，播放／暂停用高对比圆形按钮，前后跳转、上一集和下一集放在两侧。电影省略切集，剧集首尾禁用无目标的一侧。
- 字幕和音轨从右上方展开单选面板，当前选项用蓝色和对勾标记。字幕菜单提供自动、关闭及外挂字幕，控制区展开时字幕上移，避开进度条。切换音轨后留在原播放位置。
- 可点击稿以示例画面和轨道演示交互，支持拖动进度、切换字幕及音轨、跨季切集，以及返回进入播放器前的页面。
- 当前集自然播完后自动播放下一集，沿用当前全屏页面。末集播完停在播放器。
- 正常播放时，顶部和底部工具栏在 5 秒无操作后一起隐藏，点画面重新显示。暂停、缓冲、拖动进度条和字幕或音轨菜单打开时保持显示，操作结束或恢复播放后重新计时。

## Logo 与开屏

- [品牌标识](logo.png)是透明底 512×512 PNG，由亮蓝屏幕轮廓和白色播放三角组成。首页顶栏使用这个图形和「z-jellyfin」字标。
- [App 图标](app-icon.png)是 1024×1024 的方形 PNG，标识居中并留出系统图标裁切空间。底色从蓝灰过渡到近黑。
- [开屏](index.html?screen=splash)在近黑背景中央显示标识、z-jellyfin 和「家庭影音」，蓝色光晕和细圆环用于强化识别。可点击稿中，点击开屏即可预览首页；淡入遵循系统的减少动态效果设置。
- Android 12 及以上先显示系统启动标识，再过渡到品牌开屏。已保存连接配置时，开屏期间开始自动登录；连接耗时较长时显示状态和连接设置入口。

## 数据状态与原生交接

- 原版和大字版的横向卡片栏支持桌面鼠标按住拖动；水平移动达到 8 px 后视为拖动，松手吸附到最近卡片。拖动不选择文字、不触发播放或详情；普通点击及键盘操作保持有效，触屏和触控板沿用原生滚动。本行为仅用于交互设计稿，不涉及 App 实现。

- Android 媒体库顶栏高 56 dp，背景与内容同为近黑，返回、搜索、设置使用透明底并保留 44 dp 点击区域。标签栏上方不留额外内边距，标签高 44 dp，距首排海报 12 dp；选中标签为蓝色粗体和短下划线，未选中文字为 `#b8b8b8`。标签栏固定，列表在下方滚动。
- Android 列表按添加时间倒序，采用服务端聚合结果。在列表顶部下拉时显示蓝色刷新指示，刷新成功替换当前标签的首批内容；失败保留旧列表并显示重试。切换标签和详情返回保留浏览位置，上滑分页继续追加。

- 首页各区块独立加载。加载中保留区块标题与等比例占位，失败时在区块内提供重试；无续播记录时显示「暂无未看完的影片」，空的「接下来」和「最近添加」可收起。
- 媒体库上滑接近底部时自动追加下一页，加载中在列表末尾显示提示。首屏或分页失败时提供重试，分页失败保留已有内容。海报缺失或失败使用等比例占位，标题和点击入口照常显示。播放详情缺少年份、时长或简介时省略对应字段。
- 确认通过后，原生设置页可显示连接中、成功，或代理、服务器、授权对应的错误；临时失败保留上次成功配置。首次配置和更新已保存配置的确认规则以功能需求为准。
- 可点击稿使用示例数据，支持浏览、搜索、切季、模拟续播和设置确认。加载、缺图、网络故障和分页失败的样式行为在本说明中定义，真机和真实服务交由原生实现验收。
