# z-jellyfin UI 设计

[打开可点击设计稿](index.html) · [全屏播放器](index.html?screen=player) · [首页预览](首页预览.png) · [开屏预览](开屏预览.png) · [媒体库功能需求](../requirements/媒体库功能需求.md)

浏览页面向手机竖屏，播放器面向横屏。首页优先展示未看完的影片，媒体库从底部导航进入。桌面评审视图左侧可直接切换页面，点击「全屏播放器」可查看宽屏设计。

## 页面

| 页面 | 布局与操作 |
| --- | --- |
| 首页 | 首屏优先展示大幅横向「继续观看」卡片，封面底部显示进度条，封面下方显示季集号及已看时间。下面是横向浏览的「接下来」和采用 2:3 海报的「最近添加」。「继续观看」和「接下来」都在封面右下角提供半透明播放按钮，分别从保存位置或片头起播，退出播放回到首页。点卡片其他区域进入详情。 |
| 媒体库与搜索 | 顶部横向标签使用当前账号可访问的 Jellyfin 视频媒体库名称。「全部」默认选中，直接展示电影与剧集；选择具体库时直接展示该库的媒体。结果采用 2:3 海报网格，标题最多两行，点击进入详情。常规手机三列，窄屏两列。搜索复用相同卡片，返回时保留搜索词和浏览位置。 |
| 电影与单集详情 | 封面向页面背景渐变，片名、元数据和简介依次排列。有进度时主按钮为「继续观看」，旁边保留「从头播放」，并展示已看时间；已看完时使用「重播」。 |
| 剧集详情 | 「选集」下横向显示季标签，多季时可滑动，单季直接列出集数。每集显示封面、集号、标题和时长；已看完的单集显示带对勾的「已看完」，续播中的单集显示已看时间。 |
| 全屏播放器 | 播放时画面铺满横屏播放器，并按原始比例适配。左上角是返回和集名，右上角是字幕、音轨；底部显示进度、时间、画质上限和播控。点画面可显示或隐藏控制区。 |
| 连接设置 | 用标题和分隔线组织「家庭 HTTP 代理」「Jellyfin 授权」「播放画质」，输入框使用下横线，密码遮挡。画质沿用原型中的 Jellyfin 档位，默认 1080p／4 Mbps，码率为音视频合计。 |
| 保存确认 | 点击「保存并连接」后弹窗输入确认密码。错误状态显示在输入框下方，留在弹窗重试；取消保留原有保存值和页面草稿。确认成功后在保存按钮下方说明结果。 |

## 视觉与布局

- 配色来自 Jellyfin Web 默认 Dark 的核心色值。页面背景 `#101010`、面板 `#202020`、主文字 `#FFFFFF`、次要文字 `#B8B8B8`。亮蓝 `#00A4DC` 用于主操作和续播进度，配深色前景 `#061820`。媒体库选中项使用蓝色文字和短下划线，季标签、底部导航选中项和「已看完」使用淡蓝底搭配蓝色文字或图标。 [Jellyfin Web 12.4 默认深色主题](https://github.com/jellyfin/jellyfin-web/blob/v12.4/src/themes/_base/theme.ts#L5-L30)
- 页面边距常规 20、窄屏 16；区块标题 20，详情片名 30–36，主要按钮高 48，图标、季标签和设置输入框的触控区域至少 44。以上尺寸在原型中使用 CSS px，原生端按 dp／pt 和系统字体缩放适配。
- 海报采用 2:3，首页续播与接下来封面、剧集单集缩略图采用 16:9；渐变遮罩保证叠在封面上的入口文字和进度清晰。横向卡片栏露出部分下一张封面以提示滑动。
- 底部导航固定显示「首页」「媒体库」「设置」。当前入口通过底色和文字突出，按键焦点有独立描边。

## 全屏播放

- 用上下渐变保证控制区对比度。底部进度条沿用亮蓝色，播放／暂停用高对比圆形按钮，前后跳转、上一集和下一集放在两侧。电影省略切集，剧集首尾禁用无目标的一侧。
- 字幕和音轨从右上方展开单选面板，当前选项用蓝色和对勾标记。字幕菜单提供自动、关闭及外挂字幕，控制区展开时字幕上移，避开进度条。切换音轨后留在原播放位置。
- 可点击稿以示例画面和轨道演示交互，支持拖动进度、切换字幕及音轨、跨季切集，以及返回进入播放器前的页面。
- 当前集自然播完后自动播放下一集，沿用当前全屏页面。末集播完停在播放器。

## Logo 与开屏

- [品牌标识](logo.png)是透明底 512×512 PNG，由亮蓝屏幕轮廓和白色播放三角组成。首页顶栏使用这个图形和「z-jellyfin」字标。
- [App 图标](app-icon.png)是 1024×1024 的方形 PNG，标识居中并留出系统图标裁切空间。底色从蓝灰过渡到近黑。
- [开屏](index.html?screen=splash)在近黑背景中央显示标识、z-jellyfin 和「家庭影音」，蓝色光晕和细圆环用于强化识别。可点击稿中，点击开屏即可预览首页；淡入遵循系统的减少动态效果设置。
- Android 12 及以上先显示系统启动标识，再过渡到品牌开屏。已保存连接配置时，开屏期间开始自动登录；连接耗时较长时显示状态和连接设置入口。

## 数据状态与原生交接

- 首页各区块独立加载。加载中保留区块标题与等比例占位，失败时在区块内提供重试；无续播记录时显示「暂无未看完的影片」，空的「接下来」和「最近添加」可收起。
- 媒体库上滑接近底部时自动追加下一页，加载中在列表末尾显示提示。首屏或分页失败时提供重试，分页失败保留已有内容。海报缺失或失败使用等比例占位，标题和点击入口照常显示。播放详情缺少年份、时长或简介时省略对应字段。
- 确认通过后，原生设置页可显示连接中、成功，或代理、服务器、授权对应的错误；临时失败保留上次成功配置。首次配置和更新已保存配置的确认规则以功能需求为准。
- 可点击稿使用示例数据，支持浏览、搜索、切季、模拟续播和设置确认。加载、缺图、网络故障和分页失败的样式行为在本说明中定义，真机和真实服务交由原生实现验收。
