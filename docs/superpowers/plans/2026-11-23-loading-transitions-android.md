# Android 统一加载过渡实施

当前 master；保留未提交的已确认设计稿，不改代理、授权、画质、卡片回调及手势保护。

1. 新增 LoadTiming 与检查：150ms 骨架阈值、6s 较慢提示、完成后取消，不设最短等待。先观察失败再实现。
2. LoadingUi 提供固定尺寸 Skeleton（首页、网格、详情、集列表）、低对比扫光、减少动画设置、内容及图片局部淡入、页尾指示器和固定刷新反馈。
3. MainActivity 接入按页面／搜索序号／季请求号约束的 PendingLoading，完成或脱离窗口取消延时。首次加载骨架、刷新保留内容与失败原位重试、分页只更新页尾；保留分页与浏览位置，刷新后不混入旧分页。
4. 搜索保留输入与键盘，仅结果区改变；详情使用已有标题，切季只更新列表；图片不阻塞内容呈现。
5. 版本0.6.27（41）。构建、既有检查及LoadTiming检查，荣耀覆盖安装；验收四页、刷新、分页、父剧详情和播放图标、边界滑动及续播。真实空数据和失败不通过清空账号或改服务制造；注明验证范围。
