# 电影系列顺序播放计划

**目标：** 合集详情提供蓝色「播放」按钮，按 Jellyfin 成员顺序连续播放电影，末部自然结束返回合集。用户已确认顺序连播；在当前分支实施，不自动提交。

**方案：** 复用成员查询、详情操作区和现有切流/结束流程。单次点击完整读取分页队列，保留服务端顺序，仅包含直属 Movie；不展开剧集或嵌套合集。第一部未看完的电影为起点，有进度续播；全看完则从第一部开始。不改变点成员卡片进入电影详情的行为，普通电影单独播放仍结束即返回。

- [x] 用本地代理检查队列跨页顺序、成员过滤、起点、空队列及边界；旧版检查因缺少队列类而失败。
- [x] 增加独立 `CollectionPlayback` 队列；成员查询失败不启动部分队列。按钮准备期间禁用，失败恢复可重试，过期页面/账号响应不启动播放。
- [x] 在合集详情原播放区的右侧提供按钮；开始和退出沿用浏览位置记忆。按钮不加入标题列，避免增加标题列高度而挤低封面。
- [x] 播放器用完整队列确定上一部/下一部；成功切换后更新成员位置。复用现有字幕、音轨、画质及切流失败回退，末部结束沿用自动返回。
- [x] 构建并在荣耀验证受控连播、末部返回、普通电影不受影响，清理测试包。
- [x] 更新需求与版本至 0.6.52，记录验证边界。

Android 实施；iOS 本轮不修改。集合快照在本次播放器生命周期内有效，不跨会话恢复队列。合集中已看完的后续成员仍按顺序播放，不自动跳过；播放和网络失败不跳片。
