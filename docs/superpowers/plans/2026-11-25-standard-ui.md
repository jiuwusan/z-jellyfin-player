# Android 标准 UI 与大字模式

依据已确认的 [标准设计](../../prototype/standard/设计说明.md) 实现 Android；按用户最新确认默认使用标准模式，保留已保存的选择。当前 master 工作，不创建分支，不提交推送，不修改 Hub、Jellyfin 或其他服务配置。

1. 添加模式切换回归，先确认现有设置没有「长辈模式」开关。新增本地显示偏好与显式的大字/标准尺寸选择，不改变系统 fontScale 或缩放整个 View 树。
2. 共用 LibraryUi、媒体 RecyclerView 与页面数据；标准模式使用三列、常规字号、图标工具栏、紧凑导航、相同的首页卡片点击规则。切换重建显示，不重置连接或清除数据缓存；布局改变后按媒体条目恢复可见内容。
3. 详情保持背景渐变与封面叠放，标准模式播放区在封面右侧；设置保留订阅/播放两 Tab，在播放页添加本地界面开关。字幕大小与位置保持原播放策略，标准播放器缩小工具栏和中央控制尺寸，至少保留 44dp 触控区域。
4. 同步加载组件的字号与骨架列数，保留分页、刷新、缓存、防误触与已有字幕/音轨/连播规则。
5. 构建 0.6.59（73）覆盖安装荣耀原用户，使用已保存订阅的 HTTP 代理验证 API/海报/HLS、硬解、拖动、返回与模式持久化。测试不写入真实链接或密码，不绕过下发代理，也不更改保存的订阅。

完成后记录受控与真机证据，清理测试包与本轮设备端临时文件，留标准模式供用户试用。iOS 本轮不实现。

## 实施结果

Android 0.6.59（73）已覆盖安装荣耀原用户。模式开关受控测试、标准／大字播放器控制测试、千条媒体回收与布局切换位置恢复测试通过。标准设置重建保留同步失败提示；从顶部切换后保留首页标题；底部导航按标准字号展示。

真实订阅 HTTP 代理路由断言覆盖 API、图片、HLS 与分片。《魅影神捕》实际 H.264 1920×804，硬件解码器 c2.qti.avc.decoder；播放、拖动、返回及模式持久化通过。证据与边界见 [验收记录](../../requirements/Android标准版UI验收.md)。未修改 Hub 或其他服务配置，未提交或推送。
