# 首页下拉刷新

当前 master，Android 实施，保持代理、授权、播放策略及卡片事件规则。

- 首页复用已有 SwipeRefreshLayout，包裹页面 ScrollView，仅到顶部才能下拉刷新，加载及剧集播放目标查询期间不重复发起刷新。
- 每次加载重新调用 HomeFeed.load：先查续播，确认为空才查最近添加。首次显示加载状态；刷新保留旧卡片，成功后统一替换；失败停止指示器并保留旧内容，首次失败可点重试。
- 使用页面代数忽略离开页面后的结果，不修改 LibraryUi 的滑动防误触、详情和播放回调。
- 版本 0.6.26（40），构建、既有 HomeFeed/TapGesture/PlaybackPolicy 检查及荣耀覆盖安装。验收真实下拉刷新、详情／图标轻点和防误触；不清空真实观看记录，无续播使用受控分支检查。
