# 卡片和播放图标滑动防误触

当前分支直接修改 Android，不改代理、授权、画质和服务端。

- 既有复现：荣耀顶部在大卡片内向下拖动，松手进入详情。普通 View 的点击未检查移动距离，内容无可滚动范围时父 ScrollView 未取消子控件点击。
- 先用纯 Java 检查验证系统阈值内轻微抖动、超阈值、滑回原处、快速抬手、取消及下一次触摸重置。
- TapGesture 只记录本次手势是否超过阈值。LibraryUi 为所有海报卡片和首页播放图标安装触摸保护，使用 ViewConfiguration.getScaledTouchSlop；MOVE 检查历史点及当前点，UP 复查最终位置；多指或取消均禁止点击。超阈值向原控件发送 ACTION_CANCEL，取消按压与待触发点击，不阻止父列表滚动，不拦截键盘及无障碍 performClick。
- 版本 0.6.25（39），构建后覆盖安装荣耀；验证上下边界拖动、播放图标拖动无跳转，普通卡片轻点与图标轻点仍分别打开详情／播放。保留已保存连接，不提交推送。

执行结果：TapGestureCheck 初次因缺少 TapGesture 类失败，加入实现后全部检查通过；assembleDebug 成功，荣耀已覆盖安装 0.6.25（39）。五组拖动：顶部卡片下滑、底部卡片上滑、图标上下滑动、卡片滑出再返回，均未进详情或播放。3／4 px 微动后进入父剧详情，普通图标点击续播至约14:57，媒体库正常滚动，最终返回首页。未修改服务或已保存连接配置，未提交推送。
