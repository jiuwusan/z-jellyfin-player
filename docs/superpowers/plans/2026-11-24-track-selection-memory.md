# 音轨字幕记忆与连续选集实施计划

**范围：** Android 当前分支，不自动提交或推送，不修改服务端配置；iOS 待实现。

**设计：** 播放开始/进度/停止上报当前实际 Jellyfin 轨道索引，关闭字幕为 -1，自动模式解析成实际索引，不上报客户端 AUTO(-2)。上报入队时快照选择，避免切换后旧片源停止事件误报新轨道。同一影片再次播放仍采用服务端默认值，是否记忆遵循账号开关。

连续切集仅继承用户手动选择的偏好，不复制索引：按语言、原始轨道标题、强制/听障/评论标志匹配；编码用于同语种候选排序，歧义或不可用则服务端默认。字幕关闭保持，自动字幕清除手动偏好；本地独有且无法映射的轨道不伪造 Jellyfin 索引。跨剧不继承；失败切换不提交新偏好。
