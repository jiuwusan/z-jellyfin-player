# 媒体长列表回收渲染

已确认范围：仅第一优先优化，当前 master 开发，不改首页、查询、代理、播放与画质策略。

1. 补图片重复绑定回归，复现旧图片残留；实现显式解绑、移除旧监听器与异步结果归属校验。
2. 媒体库和合集改为单个 RecyclerView：卡片回收复用，合集顶部详情和分区标题全宽显示，不嵌入 ScrollView。保留分区、服务端顺序、分页、刷新与防误触。
3. 用条目锚点和偏移保存返回位置，分页插入分区也不跳动。覆盖长列表视图数量有界、复用、位置、分区和图片竞态。
4. 构建并在荣耀验证；提交和推送按用户后续明确指示执行。暂不改变图片解码尺寸、缓存键、缓存预算或新增磁盘缓存。

- 荣耀受控 1000 条电影列表多次跳转，附着卡片最多 7 张；海报尺寸、条目锚点恢复、晚出现分区、复用后的点击目标及合集头部检查通过。
- 真实 Activity/API 解析链路受控检查通过：按类型与时间排序查询、自动分页、分页失败重试、缓存返回零重复数据请求、刷新失败保留数据与位置、刷新成功替换并回到顶部。
- 荣耀真实合集《速度与激情》10 部、《人类清除计划》4 部的成员顺序与服务端一致；成员详情返回及外层列表位置恢复通过。原测试假定离屏条目仍有 View，已改为核对逻辑条目，再定位可见卡片。
