# 首页模块与模式布局实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. 不创建分支，不提交或推送；全量审查在实施后进行。

**Goal:** 标准首页显示横向的继续观看、接下来和最近添加；长辈首页纵向显示首个有内容的列表。

**Architecture:** HomeFeed 保存三个列表的同一轮快照，共用 API、连接与缓存。HomeContent 按本地模式组合模块，HomeRail 回收横向卡片并保存逻辑浏览位置。MainActivity 保留现有刷新、加载过渡和停止上报顺序。

**Tech Stack:** Android Java、RecyclerView、现有 OkHttp/Jellyfin API、HTML/CSS 原型。

**Spec:** docs/prototype/首页模式设计.md 及用户后续确认：最近添加所有卡片没有播放图标，单集进入所属剧集详情。

## Global Constraints

- 当前 master；Android 0.6.60（74），默认标准模式，保留本地长辈模式开关。
- 继续观看和接下来：图标播放／续播；卡片详情，单集进剧集详情。
- 最近添加：无播放图标，只进详情；合集进入成员列表。
- 长辈模式按继续观看、接下来、最近添加兜底，仅三者都空时展示空状态。
- 保留代理、自动登录、画质、字幕音轨、回收图片、缓存、分页、刷新和滑动防误触。
- 荣耀使用现有订阅下发 HTTP 代理，不修改服务配置；iOS 不实施。

## Review Focus

- 请求失败不能当空列表而误换兜底；保留旧内容并重试。
- 三种列表的卡片点击策略，最近添加不能存在隐藏的播放入口。
- 横向拖动和上下滑动边界不能误触，横向浏览位置返回后保留。
- 播放返回及时更新本地进度，后续停止上报成功才由服务端覆盖。
- 切换模式复用三列表快照，冷启动重新取数据；图片与 View 不写入会话数据缓存。
