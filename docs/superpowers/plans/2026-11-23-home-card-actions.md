# 首页卡片与播放图标事件拆分

范围：当前分支 Android 与大字交互原型。首页两种状态均适用；媒体库和详情内选集维持原规则。

1. 验证现状：点击续播卡片标题仍直接打开播放器，未满足详情规则。
2. LibraryUi.homeList 分别接收详情和播放回调，卡片只打开详情；播放图标使用独立至少 56dp 点击区域，视觉仍 44dp，阻止事件落到卡片。所有首页卡片均有播放图标。
3. MainActivity 首页详情将单集 ID 映射至 SeriesId，缺失则提示，绝不显示单集详情。电影图标直接播放，有进度续播；剧集图标沿用详情的目标选择（未完成进度优先，再首个未看，最后首集）。异步回调检查页面代数，防连点。
4. 原型使用同级独立按钮，避免按钮嵌套，新增首页详情／播放动作，并验证电影、单集、剧集及键盘可访问性。
5. 版本 0.6.24（38），构建并安装荣耀，真机验证点标题进入父剧、点播放图标直接续播、退出回首页；更新文档，保留配置，不提交推送。

验收结果：改动前原型点标题得到 player（期望 detail）；改动后两种首页的单集／电影卡片主体进入详情，图标命中播放按钮，无嵌套按钮；剧集图标选择首个可用目标。构建成功，荣耀 0.6.24（38）已安装；实测《魅影神捕》卡片打开父剧详情、图标从约14:44续播，电影卡片进入含从头播放入口的电影详情。最近添加暂无真实空续播账号，使用交互原型验证。
