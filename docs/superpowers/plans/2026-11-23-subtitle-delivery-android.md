# Android 图片字幕烧录修复

目标：文本由Media3绘制，图片由Jellyfin烧录；自动遵循默认轨，切换/关闭从当前位置继续，保留代理、音轨和画质。已获用户确认。当前分支实施，不修改服务配置或媒体文件，不自动提交/推送。
