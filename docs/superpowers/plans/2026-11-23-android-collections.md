# Android 合集适配实施计划

目标：按已确认方案适配 Jellyfin BoxSet，保留现有代理、自动登录、画质和列表交互。仅 Android 与验收文档；当前分支开发，不改服务配置，不自动提交或推送。

## 步骤

- [x] 请求检查先在旧版复现合集类型错误（RED），实现后通过。
- [x] `JellyfinApi` 修正BoxSet识别、合集库和成员查询；未知数量不显示为0（RED→GREEN）。
- [x] `LibraryUi` 增加合集卡片标识，复用图片、缺图占位和防误触。
- [x] `MainActivity` 增加合集页，复用背景/封面/简介，展示成员且不直接播放；保留刷新、分页和位置。
- [x] 0.6.29覆盖安装荣耀，两组真实合集成员顺序及详情往返、内外位置检查通过；加密设置逐字节未变。
- [x] 混合分区、分页锚点、刷新、空数据和同名保留受控检查通过；只读代码评审无重要问题。实际覆盖与限制见[验收记录](../../requirements/Android合集适配验收.md)。

排序口径：普通列表和合集列表添加时间倒序；合集成员不指定 SortBy/SortOrder，交由服务端决定。不按名称或元数据重新聚合，不在分页后展开或删除成员。

页面口径：仅有电影时不加多余分区标题；混合成员按类型展示。点电影进入电影详情、剧集进入剧集详情、嵌套合集进入下层。沿用既有单集播放行为。

实际服务：当前账号没有boxsets UserView，显式BoxSet查询为0，但普通Movie查询返回折叠后的BoxSet，详情及直接成员读取有效。不能以独立查询为0推断没有合集。

测试校准：程序化fullScroll尚未结束时采集位置会造成13px误报，改为同步scrollTo后通过。网格顺序用实际视图遍历核对，不以同一行的Y坐标判断先后。
