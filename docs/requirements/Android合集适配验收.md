# Android 合集适配与验收

日期：2026-11-23；版本：0.6.29（43）；设备：荣耀 BVL-AN00。Android已实施，iOS暂未实施。保留现有包名、调试签名和加密设置，未修改服务配置、媒体文件或元数据。

## 行为

- 普通列表沿用类型查询及添加时间倒序，不强制指定合集折叠；识别返回的BoxSet，不按名称或外部元数据聚合。
- boxsets媒体库查询BoxSet；服务端未返回该入口时不自行添加标签。
- 合集卡片显示封面、名称和合集标识；可靠ChildCount才显示数量，未知数量不当作0、不由当前页条数推算。
- 合集页沿用背景、封面、标题和简介，隐藏合集级播放、续播、进度和时长。
- 成员指定ParentId、Recursive=false、CollapseBoxSetItems=false，不传SortBy/SortOrder，保持服务端顺序。
- 纯电影直接展示网格；混合内容按类型分区，各类型内保持返回顺序。同名成员保留各自ID，不自行去重或展开嵌套合集。
- 电影/剧集进入详情、嵌套合集进入下层，单集沿用直接播放。保留刷新、分页、防误触和内外层浏览位置；分页插入分区时保留屏幕锚点。

## 实际服务

当前账号UserViews只有电影和剧集，没有独立合集入口；全局及电影库范围的显式BoxSet查询返回0。然而普通电影列表确实返回折叠的“速度与激情（系列）”“人类清除计划（系列）”等BoxSet，按ID读取详情和成员均有效。本轮以这些真实返回条目验收，没有修改服务设置。

## 范围限制

真实样本均为单页电影合集。独立合集库通过受控请求验证，混合分区及分页通过本地视图检查。真实嵌套合集往返、超过36项的真实合集和断网刷新失败未完整真机验证；既有错误恢复和页面身份过滤继续复用并静态复核。

没有重做播放器，也未复测全部字幕、音轨和连播。本轮未重复运行此前受历史DisplayCutout NewApi错误阻挡的全量Lint，不能称为Lint通过。
