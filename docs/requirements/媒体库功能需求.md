# Jellyfin 原生客户端功能需求

- 项目：Jellyfin Playback Probe
- 阶段：0.2.0 之后的媒体浏览迭代
- 日期：2026-11-21
- 状态：待评审

## 目标与范围

让家庭用户打开 App 后直接看到自己的媒体库和观看进度，能从海报找到电影或剧集，并在少量操作内开始播放或续播。页面全部由独立 Android 项目原生实现，媒体数据与观看记录来自 Jellyfin API。功能以家庭场景为准，无需覆盖官方 Jellyfin 的全部功能。

本期覆盖代理与授权、首页、媒体列表和媒体详情。沿用现有播放器、HTTP 代理、自动登录及 1080p／4 Mbps 转码规则。收藏、下载、投屏、服务器管理和多人账号快速切换留待后续。

## 1. 代理与授权

| 功能 | 需求 |
| --- | --- |
| 家庭代理 | 支持设置 HTTP 代理地址、端口、用户名和密码。代理用于 Jellyfin API、海报和视频流。沿用现有保存和连接验证机制。 |
| Jellyfin 授权 | 支持设置 Jellyfin 服务器地址、账号和密码。密码默认遮挡，敏感信息继续保存在当前 App 的加密存储中。 |
| 首次使用 | 从连接设置保存并成功登录后进入首页。代理连接失败、服务器不可用和账号验证失败应给出能区分的提示，允许重试或返回对应设置。 |
| 日常启动 | 配置有效时自动登录并打开首页。暂时取不到数据时显示重试入口，保留之前已验证的配置。用户可从首页主动打开连接设置。 |
| 升级保留 | 同包名、同签名覆盖安装后，已保存的代理和授权仍可使用。首次从旧验证包迁到新包需要重新配置。 |
| 播放画质 | 分辨率和码率上限使用 Jellyfin Web 档位，默认 1080p／4 Mbps。码率按音视频合计的编码预算计算。 |
| 保存确认 | 更新已保存的代理、授权或画质时，在点击「保存并连接」后弹出确认密码。取消或验证失败时保留上次成功保存的配置。 |

## 2. 首页

首页从上到下显示「继续观看」「接下来」「最近添加」。顶部提供搜索和连接设置入口，媒体库从底部导航进入。电影和剧集使用海报卡片，横向浏览。卡片整块可点，标题最多两行，海报、文字和操作在不同屏幕宽度下保持可读。

| 区块 | 展示内容 | 点击行为 |
| --- | --- | --- |
| 继续观看 | 已开始且有可续播进度的电影和单集，按服务器返回顺序显示。每张卡片显示海报、片名或剧名与集号、进度条和已看位置，有时长时同时显示总时长。 | 进入该电影或该集的详情，主按钮为「继续观看」。从服务端保存的位置起播，保留「从头播放」入口。 |
| 接下来 | Jellyfin 为当前账号返回的下一集，使用剧集海报并显示剧名、季集号和集名。已出现在「继续观看」的同一集在本栏跳过。 | 进入对应单集详情，可开始播放。 |
| 最近添加 | 最近入库的电影和剧集，沿用服务器返回顺序。按剧集聚合时，每部剧只占一张卡片。近期新增内容可以与其他区块同时出现。 | 打开对应电影、剧集或单集详情。 |

- 电影使用主海报。剧集使用剧集主海报。单集优先使用自己的封面，缺失时使用所属剧集海报。缺图或取图失败时保留固定比例的占位和可点击标题。
- 续播进度以服务端的播放位置和总时长计算，比例限制在 0% 至 100%。缺少总时长时仅显示已看位置。退出播放并回到首页后，刷新相关观看状态。
- 三个区块独立加载。单个区块失败时在该处提供重试，已加载的区块继续可用。「继续观看」为空时显示简短说明，「接下来」和「最近添加」为空时可收起对应区块。
- 首屏优先显示区块和标题。海报按需加载并复用缓存，慢图或坏图不会阻塞选片与播放。

## 3. 媒体列表与详情

### 媒体列表

- 从底部「媒体库」进入。「全部」默认选中，直接展示当前账号可访问的电影和剧集。顶部其余横向标签取自 Jellyfin 中实际创建、当前账号可访问的视频媒体库。选择库标签后在同一位置直接展示该库内容。影片和剧集采用响应式海报网格，点击进入详情。
- 列表使用服务端分页，默认按标题排序。上滑接近底部时自动加载下一页，并把新条目追加到当前列表。返回列表时恢复此前的库、目录和浏览位置。搜索继续保留，结果可进入同一详情页。
- 正常、加载中、空结果和加载失败均有对应状态。后续页失败时保留已加载内容，并允许重试。

### 媒体详情

| 对象 | 展示与操作 |
| --- | --- |
| 电影或普通视频 | 海报、片名、年份、时长和简介。没有保存进度时显示「播放」，有进度时显示「继续观看」和「从头播放」。 |
| 剧集 | 剧集海报、剧名、年份和简介。可选择季并浏览该季集数，集卡显示季集号、集名及已有观看状态。只有一季时直接展示集列表。 |
| 单集 | 海报、剧名、季集号、集名、时长和简介。按电影相同规则提供播放和续播。 |

资料缺失时省略对应字段，保留可用的播放操作。播放结束或退出后继续向 Jellyfin 上报进度。从详情返回首页时，续播和接下来区块反映更新后的状态。

## 4. 播放与设备验收

- 继续使用当前集成播放器。超出 **1920×1080** 的源视频由服务端缩放并输出 **H.264/AAC HLS**，保持宽高比例，音视频合计编码目标不超过 **4 Mbps**。符合尺寸的片源沿用现有协商流程。
- 主要开发和调试设备为 **OPPO Reno5 K（PEGM10）**。红米 Note 17 Pro 已完成上一轮硬解验证，本迭代的日常 UI 调试在 OPPO 上完成。
- 验收使用独立项目的验证版 APK，现有 Jellyfin 客户端和服务端配置不在本期改动范围。

| 验收项 | 通过条件 |
| --- | --- |
| 覆盖安装和启动 | OPPO 安装验证版，首次设置后重开可自动进入首页。同包名覆盖已有验证版时，代理和授权配置保留。 |
| 首页和海报 | 继续观看、接下来、最近添加按顺序展示。电影和剧集使用海报；缺图可继续操作；单区块出错后可独立重试。 |
| 浏览与详情 | 进入媒体库即看到电影和剧集海报。切换到实际库名标签后只显示该库内容。点击海报可看详情，剧集能进入季和单集。返回时保留选中的标签和列表位置。 |
| 续播 | 从首页选中一条有进度的电影或单集，详情展示正确位置和进度，并可从该位置起播。退出后，首页显示更新后的进度。 |
| 接下来与最近添加 | 同一集优先出现在「继续观看」，「接下来」不重复出现该集。最近添加的条目可进入对应详情。 |
| 4K 播放回归 | OPPO 使用验证版播放《魅影神捕》第 1 集，核对实际下发 **1920×804 左右**的 H.264、4 Mbps 编码目标和硬解首帧。普通 1080p 片源继续沿用现有流程。 |

## API 对照

- **媒体库、列表与详情**：沿用现有 UserViews、Items、影片详情和主图 API。
- **继续观看**：沿用现有续播接口和 Jellyfin 的进度上报逻辑，以当前授权账号的数据为准。
- **接下来**：使用 Jellyfin 的 Next Up 接口，关闭可续播条目的返回选项，并核对与首页续播区块的重合项。[Jellyfin 10.11.11 Next Up 接口](https://github.com/jellyfin/jellyfin/blob/v10.11.11/Jellyfin.Api/Controllers/TvShowsController.cs#L72)
- **最近添加**：使用 Jellyfin 的 Latest Media 接口，沿用服务端返回的排序及当前账号的显示设置。[Jellyfin 10.11.11 Latest Media 接口](https://github.com/jellyfin/jellyfin/blob/v10.11.11/Jellyfin.Api/Controllers/UserLibraryController.cs#L487)
