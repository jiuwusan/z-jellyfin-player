# 中文音轨与字幕自动选择：实施前抽样

日期：2026-11-24。状态：只读抽样完成，未修改选轨代码、账号设置、媒体文件或服务配置。用于细化已讨论的“国语优先、简体优先”，不是首播效果验收。

## 抽样方式与覆盖

先按添加时间的新、中、旧位置抽取 60 部电影，再轻量筛查当前账号可见的 136 部真实电影缓存元数据，以补查文本/外挂字幕等稀有情况。查询显式关闭合集折叠，避免把无音轨的 BoxSet 当作电影。剧集选择 10 部，取首集、次集和可见末集；单条目的剧集/综艺只取可见条目，共 24 集。另对 12 部典型电影和 5 个单集查询 PlaybackInfo 并核对详情，共 17 个条目。

本次不播放视频、不扫描文件内容，不调整媒体元数据或用户观看状态。临时认证会话在各批次结束时退出；报告不包含地址、账号、令牌、文件路径或条目 ID。

| 指标 | 观察结果 |
| --- | --- |
| 电影 / 剧集样本 | 136 部电影、10 部剧集共 24 集 |
| 轨道数 | 391 条音轨、601 条字幕轨 |
| 字幕编码 | PGS 图片字幕、内嵌 SubRip 文本字幕 |
| 外挂字幕 | 0 条，不能宣称已用真实样本覆盖外挂 |
| 语言为空或 und 的音轨 | 18 条 |
| 没有独立字幕轨的条目 | 18 个；不代表画面没有压制字幕，未分析视频画面 |
| 标题包含 Commentary / 评论的轨道 | 127 条 |
| 标题包含 SDH / 听障的字幕 | 10 条；IsHearingImpaired 均未标为 true |
| 标题包含 Description / 视障 / 口述的音轨 | 1 条 |

这些是当前账号可见媒体的观察，不是其他媒体库的通用分布。PlaybackInfo 的默认索引可能已经包含用户记忆，不能当作“从未选择过”的首播结果。

## 典型案例

| 媒体 | 元数据现象 | 规则必须处理 |
| --- | --- | --- |
| 唐伯虎点秋香、算死草 | 粤语与国语语言字段全部 zho，标题分别含 Cantonese、Mandarin | 仅 Chinese 不足以区分；标题用于细分，不把索引当语种 |
| 龙虎门、行运一条龙、九品芝麻官 | 同时有多条 Mandarin，区别是 TrueHD / AC-3 等编码 | 同语言、同用途，仅技术规格不同的国语候选按原索引稳定选择首条，不按码率或声道高低排序 |
| 济公 | 同时有普通 Chs/SUP 原盘简体、Chs/SUP 国配简体 | 国配与原盘尚无可靠对应关系；限定语不同不视为等价，继续保留默认 |
| 猩球崛起 | 普通简体与简体 Commentary 1/2 并存 | 不能只匹配 Chs；评论用途必须从标题识别 |
| 卧虎藏龙、恶灵骑士 | Eng/SUP SDH 的听障布尔标记仍为 false | 不能只信 IsHearingImpaired；SDH 等标题证据同样需要处理 |
| 黑暗侵袭2 | 主音轨之外有 Description 音轨 | 普通自动选择不应把口述描述当主音轨 |
| 猩球崛起2、电锯惊魂8 | 纯简体与简英双语并存 | 默认先纯简体；无纯简体再考虑简英双语 |
| 电锯惊魂9：漩涡 | 中文字幕只有简英双语、繁英双语 | 简英双语可以作为简体回退，不能因不是纯简体而改选繁体 |
| 电锯惊魂10 | 字幕标题为“简中”“繁中”“英文” | 识别别名，不能只支持完整“简体中文” |
| 武状元苏乞儿 | Eng/SUP 的 Language 却是 zho | 标题明确英文时，不能仅凭 zho 把它当中文字幕 |
| 异形 | 出现 Cht/SUP 原盘简体 Commentary 2 | 标题内部同时有繁体、简体证据，应视为冲突，不作高置信度自动选择；另有评论属性 |
| 蝎子王、龙的传人、审死官等 | 中文字幕只有繁体，或港版/台版繁体两条 | 不伪造简体；无简体时沿用可用中文默认，港/台同等级时保留默认 |
| 给阿嬷的情书 | 普通话 zho 与潮汕话 min 并存 | 普通话/国语是明确目标，不能把其他汉语方言自动归入国语 |
| 功夫女足、多喜一家人 | 轨道都写“中文”，有编码不同或完全同名的 AAC 双轨 | 泛中文不能证明国语；无法细分时保留默认，不任意声称某条是国语 |
| 天下长河、奔跑吧·特别篇 | 唯一音轨为 und 或无语言 | 仍可使用唯一音轨，不报“没有国语”或猜测其语言 |
| 太阳的后裔 | 两条韩语音轨、没有独立字幕轨 | 不因中文优先而选错语种或提示不存在的中文字幕 |
| 我和妈妈的长征 | 部分集只有外语字幕，另有集没有独立字幕 | 不能将第 1 集的字幕索引原样传给后续集，不能凭剧名推断字幕语言 |

## 已确认并实施的保守规则

先检查当前会话的明确选择和跨集匹配，再检查账号语言偏好及 App 手动标记；最后才允许细分 Jellyfin 的默认值。Android 实施本轮规则，iOS 尚未接入。

| 条件 | 行为 |
| --- | --- |
| 账号首选语言为通用 Chinese（zho / chi / zh） | 才考虑国语或简体增强；不覆盖 English、明确粤语或繁体偏好 |
| 中文组少于两条，或默认不是该组按 Index 排序的第一条 | 完整保留服务端默认；第一条指中文组第一条，不是整个文件第一条 |
| 当前会话明确选择、已继承的跨集偏好、App 可确认的手动标记 | 不启用自动增强，即使用户手选的是第一条 |
| 默认是第一条且存在明确更优候选 | 音轨识别 Mandarin / 国语 / 普通话 / cmn；字幕识别 Chs / Hans / 简体 / 简中等；同等级且用途等价的多个候选取最小原索引 |
| 同等级候选用途或未知限定语不同、泛中文、冲突或信息不足 | 保留默认，不按码率、声道或编码猜测；只剥离已知技术规格，不删除未知限定语 |
| 评论、SDH、口述、强制等特殊用途 | 不作为普通自动增强目标；默认本身是特殊用途也不替换 |
| 字幕已关闭或服务端默认 -1 | 不打开字幕；Smart / OnlyForced 等依赖服务端策略的模式不二次判断 |
| 普通纯简体与简英双语并存 | 仍优先纯简体，其次简英双语；同等级且用途等价时按原索引稳定选择，用途不同则保留默认 |

自动选择仍走原有协商链：固定片源后发送音轨索引；图片字幕由 Jellyfin 烧录，文本字幕按已有投递方式由手机绘制，保留原画质和码率上限。不写账号全局设置，不扫描或修改文件及元数据。

## 手动记忆识别限制

复核的接口只返回 DefaultAudioStreamIndex / DefaultSubtitleStreamIndex。MediaSource 没有暴露默认索引来源标记，条目 UserData 也没有暴露足以区分历史手动选择的索引来源。“默认为第二条及之后时不干预”只是用户确认的保守启发式，不能证明该值确实来自手动选择；第一条也可能是历史手选。

App 按服务器、账号、条目、片源和轨道类型记录明确手动选择。仅在切换成功后记录（直接生效的选择立即记录），失败切换不新增保护；“自动”清除该字幕标记，“关闭”属于明确选择。磁盘仅保存作用域的 SHA-256 哈希和时间戳，不保存地址、凭据或媒体名称。最多保留 2048 个标记，达到上限淘汰最早标记。账号记忆开关关闭时不应用相应的持久保护，当前会话的明确选择仍优先。

已有服务端索引记忆仍由 Jellyfin 管理；App 标记只用于避免自动增强覆盖用户意图，不自行恢复字幕或音轨索引。升级前、其他客户端或标记已淘汰的手动选择不能完整追溯，不通过清空用户历史解决。

## 仍需补充的受控用例

真实样本没有覆盖外挂 SRT/ASS/VTT、明确 cmn/yue/zh-Hans/zh-Hant 标签、真实强制/听障布尔标记、含空标题的中英冲突、历史手动选择标记、多个片源索引不同等情况。应以虚构且隔离的数据覆盖，不能宣称本次抽样已经验证。也未检查字幕内容或配音实际声音，标题只能作为有边界的元数据证据。

## Android 验收入口

构建主包和 instrumentation 包后，在指定设备运行 `am instrument -w -e suite chinese-tracks cn.jiuwusan.jellyfin.player.test/cn.jiuwusan.jellyfin.player.LoadingTransitionCheck`。受控数据覆盖第一条门槛、组内索引、后续默认保护、跨登录手动标记、作用域隔离、账号记忆开关、语言与字幕模式、标题冲突及取流协商。测试不修改真实账号偏好，临时偏好存储在专用测试命名空间并在结束时清理。

原有 `track-memory`、`subtitles`、`languages` 检查继续用于跨集、烧录/文本、关闭与账号设置回归。真实影片验收只检查当前播放轨道、硬解和续播，不重置用户历史。国语/简体识别依赖元数据，不能据此承诺实际配音或字幕内容无误。

### 2026-11-24 验证记录

Android 0.6.44（versionCode 58）在荣耀验证。四组受控检查 `chinese-tracks`、`track-memory`、`subtitles`、`languages` 均返回 `ALL_PASS`。其中 `chinese-tracks` 的合成服务验证了默认第一条时协商国语音轨和简体 PGS 烧录、第二条默认保持、手动标记跨登录保护及非中文/字幕关闭等分支。

真实《唐伯虎点秋香》确认第 3 条 Mandarin 音轨正常播放，解码器 `c2.qti.avc.decoder`。再手选第 1 条 Cantonese 音轨，退出并重开 App 后仍为第 1 条，验证 MainActivity 的手选标记写入及重开保护；随后恢复第 3 条国语音轨并确认切换成功。真实播放/切换按原逻辑上报进度；未重置观看历史、修改全局语言偏好或改动服务配置。真实库不通过清空手选记录来强造首播场景，第一条自动增强的精确对照由隔离服务覆盖。
