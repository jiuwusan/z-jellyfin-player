# Android 音轨与字幕选择记忆

## 行为

播放会话的选轨与账号语言偏好分开处理。手动选择音轨或字幕不会修改 Jellyfin 的首选语言、字幕模式或记忆开关；Hub 配置保持不变。

| 场景 | 处理 |
| --- | --- |
| 同一影片退出后续播、重新打开 App | 继续采用 Jellyfin 返回的默认音轨和字幕；是否记忆由该账号的 RememberAudioSelections、RememberSubtitleSelections、字幕模式和影片能力决定 |
| 播放开始、进度、停止 | 上报本片源实际音轨与字幕索引；手机绘制的文本字幕也上报其 Jellyfin 索引，不使用转码 URL 中禁用烧录的 -1 代替 |
| 字幕自动 | 解析为当前服务端默认索引，不上报客户端 AUTO(-2) |
| 字幕关闭 | 上报 -1，同一连续播放中切集继续关闭 |
| 同剧连续切集 | 仅继承手动偏好，按语言别名、地区、原始标题及强制/听障/评论标志匹配新集，编码用于同类候选排序；不复制上一集的数字索引 |
| 缺少匹配、存在歧义、字幕不可用 | 回退到该集服务端默认值；后续集仍可重新尝试匹配原手动偏好 |
| 切换字幕为自动 | 清除本次连续播放的手动字幕偏好；重新由服务端默认选择 |
| 切到其他剧集 | 不继承上一剧的手动偏好 |
| 纯本地且无法映射为 Jellyfin 索引的轨道 | 不伪造索引，不承诺服务端记忆或跨集沿用 |

每个新播放器首帧后按顺序发送开始和进度事件：Jellyfin 通过 Progress 保存轨道选择，不能只等 10 秒定时进度或依赖 Stopped。直接切换手机字幕时立即上报进度。状态上报排队前快照轨道索引，旧流停止上报不会读取新流的选择。切换失败不提交新的跨集偏好。

连续播放偏好仅存在本次播放器会话；返回列表后重新打开不使用 App 保存的剧集偏好，而采用 Jellyfin 账号下该影片的记忆与默认策略。不增加全局语言筛选，不自动启用账号记忆开关。iOS 未实施。

## 验证记录

- 旧实现新增上报检查失败：缺少 AudioStreamIndex、SubtitleStreamIndex；修复后 `track-memory` ALL_PASS。
- 覆盖实际索引、关闭字幕、语言别名、索引变化、标题、强制/听障/评论、歧义、不可用字幕、完整跨集取流协商、MediaSourceId 绑定、手机文字字幕与未知本地轨道。
- 既有 `subtitles`、`languages` 均 ALL_PASS，烧录、字幕关闭、手机文本绘制和账号其他字段保持原行为。主 APK 和测试 APK 构建通过。
- 荣耀真实账号的两个记忆开关均开启。第 3 集选择 English 后只读 PlaybackInfo 返回 English；切到第 4 集仍选中 English。再次重开播放器实际使用上次保存的音轨，服务端默认音轨与字幕与选择一致。
- 真机验证了选轨后约 6.8 秒（含重新取流和首帧）已收到服务端记忆结果，无需等待首帧后的 10 秒定时周期。
- 测试结束将第 3、4 集恢复为原中文音轨与简体中文字幕；未修改账号的全局语言偏好、记忆开关或服务配置。播放会按正常行为更新观看进度。
- 全程实际硬解为 c2.qti.avc.decoder，输入 H.264、1920×804、60 fps；观察日志无播放错误或上报错误。临时测试包、UI 转储已清理，日志开关恢复。

验证平台仅 Android 荣耀，不宣称 iOS 或所有片源均已验收；退出后记忆仍以服务端成功接收进度及账号设置为前提。
