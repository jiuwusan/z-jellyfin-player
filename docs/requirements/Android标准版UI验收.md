## 真机播放证据

在请求拦截器中核验连接路由，API、图片、HLS 清单和视频分片均为 HTTP 代理。最近一次完整真机回归记录 API 24 次、图片 22 次、HLS 2 次、分片 8 次，没有退回直连。计数仅表示该轮测试观测值，不代表带宽测速。

《魅影神捕》收到 H.264、1920×804，硬件解码器为 `c2.qti.avc.decoder`。设备保留订阅的 1080p／4 Mbps 上限；播放、拖动后继续、退出返回通过。该回归验证取流与解码，不宣称所有媒体或长时间播放均已验收。

构建及受控测试日志保存在本机忽略目录 `verification/`：`standard-ui-final-build.log`、`standard-final-ui-mode.log`、`standard-final-fullscreen-standard.log`、`standard-final-fullscreen-controls.log`、`standard-recycled-lists.log`、`standard-final-standard-ui-real.log` 和 `standard-final-loading.log`。截图在 `verification/standard-ui/`，包含首页、媒体库、详情、播放设置与播放器，不纳入仓库。

本轮仅实现 Android 与标准版原型；iOS 未实现。保留原大字版原型。未提交、未推送。

## 截图验收后的调整

按用户确认，媒体库移除「按添加时间」可见提示及其占位，实际查询仍按添加时间倒序。Android 与标准版原型同步。订阅页验收截图不再额外隐藏服务器、代理地址和账号，保留 App 原有的订阅令牌隐藏逻辑；真实配置只保存在设备和本机忽略目录中，不写入仓库。
