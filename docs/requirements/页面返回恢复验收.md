## 边界

- 缓存仅限当前进程和登录会话；重启进程、重新连接授权或缓存被回收后需要重新加载。
- 当前浏览的媒体库分页不截断，非当前媒体库有回收上限。超限回收后的库需要重新查询。
- 本轮未实施 iOS，未修改服务端、HTTP 代理或字幕/音轨协议行为；这些不作为本轮完整回归声明。
