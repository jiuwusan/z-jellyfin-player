# 播放器首次取流加载态验收

日期：2026-11-23。Android 0.6.28（42），包名 `cn.jiuwusan.jellyfin.player`。设计依据：[播放器首次取流设计](../prototype/large-type/播放器首次取流设计方案.md)。本轮不实施 iOS，不修改 Jellyfin 或代理服务配置。

## 行为

- 进入横屏全屏后展示横版背景和深色渐变；缺图不阻塞视频。
- 150ms 后显示蓝色指示器；6 秒仍无首帧时增加「视频准备较慢，请稍候」，不按等待时长判定失败。
- 返回可用；首帧前禁用字幕、音轨、进度、播放与切集。
- 实际首帧触发约150ms 封面淡出，随后解禁控制，恢复原工具栏布局及5秒隐藏规则。
- 失败停止转圈，提供重试和返回；重试重新协商媒体，保留续播点、源、音轨、字幕偏好和画质。
- 返回、重试和视图移除清理计时器，页面及请求身份过滤旧回调。现有切轨失败恢复保持原实现。
- 短屏依据实际顶部、底部高度避让；失败说明可滚动，56dp 操作行独立固定，避免裁切。减少动画时不依赖转圈或淡出表达状态。

## 限制与清理

`lintDebug` 未通过：4 个历史遗留 `NewApi` 错误，均是 `FullscreenPlaybackView` 的 `DisplayCutout.getSafeInset*()` 调用；与本轮前 HEAD 对应源码相同，未扩大修改范围。另有现有兼容性和资源警告，完整报告在本机 Android 构建输出。构建与上述设备测试独立通过，不能称为全量 Lint 通过。

本轮仅对现有真实片源执行播放、跳转进度及会话上报；没有重新验证所有字幕格式、每种多音轨源和整季自然连播。专用测试包及设备端临时截图在交付前清理，主应用、授权和代理设置保留。
