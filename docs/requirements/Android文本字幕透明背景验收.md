# Android 文本字幕透明背景

2026-11-23，Android 0.6.38（52），荣耀 BVL-AN00。本轮仅解决客户端绘制文本字幕的黑底，不增加或修改字幕大小设置；iOS未实施，按用户指示提交并推送到当前master分支。

## 修复

默认字幕样式采用透明文本背景、透明窗口、白色文字和黑色描边。字幕文件中的BackgroundColorSpan和Cue.windowColor在显示前清除，保留原文字颜色、粗斜体、字号和定位；不直接修改Media3原始cue或缓存内容。

此处理接入现有工具栏上移逻辑，工具栏显示/隐藏时始终使用去背景后的cue，上移保持字号。图片cue原样保留；已烧录进视频的背景不在客户端处理范围。HTTP代理、授权、选轨、缓存、画质和服务配置均不变。

## 验证

- `subtitle-style`：先观察到缺少样式实现的RED；实现后ALL_PASS。实际绘制像素对照确认大片黑底消失、文字与描边仍存在，原文字颜色和粗体保留，原始cue未修改，图片cue未修改，字号与位置字段不变。
- `subtitles-text`：ALL_PASS。《魅影神捕》第2集真实文本cue显示；检查实际FullscreenPlaybackView中的SubtitleView样式及显示cue，默认背景、文件背景和窗口背景均透明，黑色描边有效。首帧与切换完成后暂停截取工具栏显示/隐藏两张图，人工查看确认无底块、上移保持字号。
- `subtitles-real`：ALL_PASS。原默认中文PGS、切英文、关闭、恢复自动及实际文本cue正常；暂停切换均保持600000ms、原音轨/画质，加密连接设置保持原值。硬解c2.qti.avc.decoder，H.264 960×400、60fps，仍在既有上限内。
- 主包和instrumentation包成功构建，diff格式检查通过。本地证据位于忽略目录 `verification/subtitle-style/`。
